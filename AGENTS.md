# Project instructions

This is an OpenCode text-to-speech plugin. See `AGENT.md` for project background.

## Command-line operations

Ask the user for approval before running command-line commands, including Git
commands and commands run through shell tools, scripts, or other indirect execution.
Explain what each command does before requesting approval. Continue using
non-command file inspection and editing tools when practical.

## Git naming

Do not prefix commit messages or branch names with categories such as `feat`,
`fix`, or `chore`. Use a clear, descriptive name without a prefix.

After making changes, suggest a commit message at the very end of the final
response.
